# Matchbox Simulator

A 3D fire playground that runs in the browser: strike matches, light a candle, and pull everyday things out of the cupboard to see how each one meets a flame.

Built with Vite, Three.js and Rapier.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build in dist/
```
